# 참가자 이름 테트리스 실시간 연출

행사 참가자 명단을 입력하면 각 이름이 테트로미노 블록이 되어 자동으로 낙하·회전·착지하며 쌓이고,
가로 줄이 완성되면 폭발하며 사라지는 실시간 관객용 비주얼입니다. React + TypeScript + Vite +
Canvas2D로 구현되어 있으며 외부 서버나 오디오 없이 로컬에서 바로 실행됩니다.

## 실행

```bash
npm install
npm run dev
```

## 사용법

1. 화면에서 `Esc`를 눌러 관리자 패널을 엽니다.
2. 참가자 이름을 한 줄에 한 명씩 입력하고 "명단 적용"을 누릅니다.
3. "시작"을 눌러 자동 진행을 시작합니다.
4. 필요하면 낙하 속도 / 등장 간격을 조절하고, 행사 로고(PNG/SVG)를 업로드합니다.
5. 행사가 끝나면 "게임 종료 및 피날레 실행" (2단계 확인) 또는 `Enter` 2초 길게 눌러 피날레를 실행합니다.

### 키보드 단축키

| 키 | 동작 |
| --- | --- |
| `Space` | 일시정지 / 재생 |
| `N` | 현재 블록 즉시 착지 |
| `R` | 초기화 후 다시 시작 |
| `F` | 전체화면 |
| `Enter` (2초 길게) | 게임 종료 및 피날레 실행 |
| `Esc` | 관리자 화면 열기 / 닫기 |

## 구조

```text
src/
  components/   AdminPanel, GameScreen, ScoreBoard, FinaleOverlay
  game/         테트로미노, 이름 블록 생성, 보드/충돌, 자동 배치, 라인 클리어, 점수, 게임 루프
  rendering/    Canvas 렌더러, 블록/파티클/이펙트
  state/        React 바인딩 (게임 엔진 싱글턴)
  types/        공용 타입
  utils/        명단 파싱, 셔플
```

사운드는 사용하지 않으며, 모든 피드백은 시각 효과로만 표현됩니다.
